这是这个网站的第一篇文章，也是一篇用于验证发布流程的测试文章。

## 为什么写下来

学习和科研中，很多有价值的想法最初都很零散：读论文时的一个疑问、调试时的一次发现，或者完成一个项目后的复盘。

我想把这些过程记录下来，让未来的自己能够回顾，也方便与有相似兴趣的人交流。

## 这里会记录什么

1. 保研准备与经验总结。
2. 论文阅读笔记与科研项目复盘。
3. 大语言模型、AI Agents 和可靠 AI 系统的学习记录。
4. 编程实践、工具使用与开发过程中的思考。

## 一篇笔记的起点

我希望每篇笔记尽量回答三个问题：

- **问题是什么？** 交代背景与目标。
- **做了什么？** 保留方法、实验和必要的代码。
- **学到了什么？** 写清结论、局限与下一步。

下面是一段用于检查代码高亮与复制功能的示例：

```python
def write_note(question: str, takeaway: str) -> dict:
    return {"question": question, "takeaway": takeaway}


note = write_note("今天学到了什么？", "先记录，再整理。")
print(note)
```

> 先把问题和过程写清楚，再慢慢完善。
